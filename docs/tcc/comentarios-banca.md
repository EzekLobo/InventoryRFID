# Comentarios da banca para correcoes do TCC

Este arquivo registra os comentarios recebidos da banca e acompanha as alteracoes
aplicadas na branch `tcc/correcoes-banca`.

Base de comparacao: `docs/tcc/base-estado-atual-v7/`

## Como preencher

Use um bloco por comentario. Mantenha o status atualizado para facilitar a
conferencia antes da entrega.

Status sugeridos:

- `pendente`
- `em andamento`
- `corrigido`
- `revisar com orientador`
- `nao aplicado`
